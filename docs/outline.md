## 三、各節重點

### 0 開場（3 分鐘）

- **開場**：2025 年 4 月，美國對中國商品的關稅一度疊加到 **145%**，中國反制到 **125%**。先問台下：「你手上的手機、身上的衣服，會因此變貴嗎？」
- 預告報告架構：什麼是貿易戰 → 歷史上的貿易戰 → 中美背景 → 經過 → 影響 → 結論。

### 1 什麼是貿易戰（3 分鐘）

- **定義**：兩個或多個國家，以提高關稅、設定配額、限制進出口等手段互相施壓，並引發對方報復的經濟衝突。
- **名詞解釋**：3 分鐘講不完全部，建議只講標 ★ 的 5 個，其餘在後面第一次出現時順帶解釋。

  | 名詞 | 說明 |
  |---|---|
  | ★ 關稅 | 對進口商品課的稅，由進口商繳納，成本常轉嫁給消費者 |
  | ★ 貿易逆差 | 一國進口大於出口。美國對中國長期有巨額逆差 |
  | ★ 保護主義／報復性關稅 | 用關稅等手段保護本國產業；對方加稅後，反過來對其商品加稅 |
  | ★ 301 條款 | 美國《1974 年貿易法》第 301 條，授權美國貿易代表署（USTR）對外國「不公平貿易行為」採取報復 |
  | ★ WTO（世界貿易組織） | 制定國際貿易規則、處理貿易爭端的國際組織，前身是 1947 年的 GATT |
  | 232 條款 | 美國《1962 年貿易擴張法》第 232 條，以「國家安全」為由限制進口，例如鋼鋁關稅 |
  | 實體清單 | 美國商務部的出口管制名單，美國企業要賣技術給名單上的公司必須先取得許可 |
  | 出口管制 | 限制特定技術或商品出口到特定國家，例如先進晶片 |
  | 匯率操縱國 | 美國財政部認定刻意壓低本國貨幣、以取得出口優勢的國家 |
  | 對等關稅 | 2025 年川普政府提出，依對方對美國的關稅與貿易障礙，課徵相對應的關稅 |

### 2 歷史上的貿易戰（5 分鐘）

- **1930 年斯姆特-霍利關稅法**：美國大幅提高兩萬多項進口商品的關稅，引發各國報復，全球貿易大幅萎縮。史學界對它加劇大蕭條的程度仍有爭論。
  - **效果與教訓**：二戰後各國在 1947 年簽訂 GATT，後來發展成 WTO，目的就是避免再次陷入關稅互相報復。
- **1960 年代「雞肉戰爭」**（可選的補充案例）：歐洲共同市場對美國雞肉課高關稅，美國以 25% 的進口輕型卡車關稅報復。這項「雞肉稅」一直沿用到今天，說明貿易戰的措施可能延續數十年。
- **1980 年代美日貿易摩擦**：
  - 美國同樣動用 301 條款施壓。
  - 1985 年廣場協議，日圓大幅升值。
  - 1986 年美日半導體協議。
  - 1987 年雷根政府對日本電子產品課徵 100% 關稅。
  - **效果**：日本最後讓步，之後日本半導體產業的優勢逐漸流失（原因很多，⚠️ 待查證）。
- **小結**：貿易戰很少有真正的贏家。它可以保護部分產業，但通常會引發報復，並提高消費者的成本。以此帶出問題：中美貿易戰也會是這樣嗎？

### 3 歷史背景（8 分鐘）

- **1979 年中美建交**，中國改革開放，逐漸成為「世界工廠」。
- **2001-12-11 中國加入 WTO**，對美出口快速成長，美國對中國的貿易逆差持續擴大。2018 年商品貿易逆差約 4,190 億美元。
- **「中國衝擊」（China Shock）**：學者研究指出，中國進口競爭與美國製造業就業流失有關（Autor, Dorn & Hanson）。
- **2015《中國製造 2025》**：中國想在半導體、航太、電動車等高科技產業自主，美方擔心被追上。
- **魚骨圖：貿易戰成因**，共五根大骨。
  - 經濟：貿易逆差、製造業流失
  - 科技：中國製造 2025、強制技術移轉與智財爭議
  - 制度：國家補貼、市場准入、WTO 規則難以約束
  - 國內政治：鏽帶選民、兩黨立場一致轉向強硬
  - 地緣戰略：霸權競爭、修昔底德陷阱

### 4 衝突經過（12 分鐘）

分成四個回合來講，每個回合約 3 分鐘。詳細日期請看下方〈五、大事記〉。

1. **關稅戰（2018–2019）**：301 調查 → 鋼鋁關稅 → 三波加徵關稅 → G20 短暫休兵 → 華為禁令 → 匯率操縱國。
2. **休兵：第一階段協議（2020-01-15）**：中方承諾兩年內增購 2,000 億美元美國商品與服務。根據 PIIE 估計，實際只達成約 58%。
3. **科技戰（2019–2024）**：戰場從關稅轉向晶片。拜登政府保留關稅，另外推出晶片法案與半導體出口管制。
4. **川普第二任期（2025–）**：關稅一路疊加到 145% 的高峰，之後經過日內瓦協議降溫，再因稀土管制升級，最後在釜山川習會休兵。
5. **2026 最新發展** ⚠️ 待查證：美國最高法院對 IEEPA 關稅案的裁決、雙方後續談判與元首互動。

### 5 影響分析（10 分鐘）

- **美國**：多項研究指出，關稅成本大多轉嫁給美國進口商與消費者（例如 Amiti, Redding & Weinstein, 2019）。農民受到中國報復衝擊，政府在 2018–2019 年提供約 280 億美元的農業援助。
- **中國**：出口轉向東協等市場，加速半導體自主與國產替代，經濟成長受到壓力。
- **台灣**：
  - 台商回流：2019 年推出「歡迎台商回台投資行動方案」。
  - 轉單效應：部分訂單從中國轉到台灣。
  - 台積電赴美設廠，科技供應鏈出現「中國＋1」的布局。
- **全球**：
  - 供應鏈移往越南、墨西哥等地。2023 年墨西哥超越中國，成為美國最大的進口來源國。
  - WTO 爭端解決機制停擺。
  - 「去風險」與友岸外包興起。

### 6 結論與提問（4 分鐘）

- 這場戰爭的本質一路升級：從貿易逆差，到科技霸權之爭，再到全面的戰略競爭。
- **回扣第 2 節，和過去的貿易戰比較**：

  | | 美日（1980s） | 美中（2018–） |
  |---|---|---|
  | 對方身分 | 盟友，安全仰賴美國 | 戰略競爭者 |
  | 爭議核心 | 貿易逆差、半導體 | 貿易逆差 → 科技霸權 → 國家安全 |
  | 結果 | 日本讓步 | 雙方互相報復、長期對峙 |

- **修昔底德陷阱**（Graham Allison）：崛起強權與既有霸權之間容易爆發衝突。這場貿易戰是不是這種結構的一部分？
- 留給台下的問題：「全球化會就此終結嗎？夾在兩強之間，台灣該如何定位？」
